# astronomy

Welcome! 

## overview

This repo contains a collection of labs that I completed for a course at UW-Madison in observational astronomy and data analysis. I wrote observing scripts to submit to the radio/optical telescope interfaces in order to collect data from the on-campus SRT and Linda-Sue 16” optical telescope in the Livingston-Stark Observatory. I then analyzed the data using Python and wrote short reports for each of 5 labs, all of which can be found here. The topics for each of the labs are:

* Optical 1: CCD characterization
* Optical 2: Photometry of star clusters
* Radio 1: Measuring the telescope beamwidth with the Sun
* Radio 2: Characterizing a radio telescope: Noise and temperature calibration
* Radio 3: Measuring the Milky Way's rotation curve

## files

You will find folders for the data, Jupyter notebooks, and reports for the aforementioned labs.
